Реляционная модель базы данных (3НФ)

Система спроектирована на основе 5 нормализованных сущностей: Clients, Cars, Masters, Services, Appointments.

Clients (Клиенты)

  • id INT PK AI
  • full_name VARCHAR(150)
  • phone VARCHAR(20) UNIQUE

Cars (Автомобили)

  • id INT PK AI
  • client_id INT FK → Clients
  • brand_model VARCHAR(100)
  • license_plate VARCHAR(15)

Masters (Мастера / Посты)

  • id INT PK AI
  • full_name VARCHAR(150)
  • post_name VARCHAR(50)
  • specialization VARCHAR(100)

Services (Услуги)

  • id INT PK AI
  • title VARCHAR(150)
  • duration_min INT
  • price DECIMAL(10,2)

Appointments (Записи)

  • id INT PK AI
  • car_id INT FK → Cars
  • master_id INT FK → Masters
  • service_id INT FK → Services
  • start_datetime DATETIME
  • end_datetime DATETIME
  • status ENUM
